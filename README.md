## Scientific basis
Current NASA catalog values for TOI-700 d: 1.073 Earth radii, 1.25 Earth masses, 37.4-day period, 0.1633 AU semi-major axis, eccentricity 0.04. The system's fourth known planet, TOI-700 e, was reported in 2023.

## Important visualization note
The planet's actual surface is not directly imaged. Any surface rendering in this repository is an illustrative simulation and must not be interpreted as an observation.
